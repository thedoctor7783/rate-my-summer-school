Set the experiment

Apply with New board. Alternating arrangements use a full board with empty corners; the book recipe then removes 20 pieces and adds 5 randomly.

Individual demands

In move mode, select an unhappy piece, then a green empty cell. Editing the board pauses play and starts a new experiment.

The rules, exactly where it matters
  1. A neighborhood is the eight surrounding squares, including diagonals. Edges have fewer squares; there is no wraparound. Vacant squares do not count as neighbors.
  2. The default requirement follows the book’s explicit table below. A piece that meets its requirement stays where it is.
  3. An unhappy piece moves to the nearest vacant square where its demand would be met. Its original square is treated as vacant when checking the destination.
  4. Moves happen one at a time. Satisfaction is recalculated after every move, including for the neighbors left behind and joined.
  5. When everyone is satisfied, the board has settled. If unhappy pieces have no satisfying destination, it is blocked. Repeated configurations are flagged as cycles.

The supplied text leaves the zero-neighbor case implicit; this simulation treats an isolated piece as satisfied under the table and fraction rules. The count rule still requires the chosen count. The A +1 / B −1 variant adds or subtracts one from the table (floored at zero).

The book does not define a distance metric or equal-distance tie-breaking. Here “nearest” means straight-line distance between cell centers; ties are selected randomly. The order choices follow the book’s suggestions. A blocked piece is skipped so others can move.

Fraction mode supports the introductory A ≥ ½, B ≥ ⅓ example. Count mode supports the later rule of seeking three like neighbors regardless of unlike neighbors. Like-neighbor share is the number of same-group occupied neighbor links divided by all occupied neighbor links; it is descriptive, not a score to maximize.

The final supplied page begins a different, bounded-neighborhood model. Its complete dynamics are not provided, so this game implements the fully described self-forming model.
